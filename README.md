# The Spike Analytics — Project ESOL Intelligence Dashboard

모바일 배구 게임 **더 스파이크(선시안)** 의 수익화 구조와 시장 지표를 분석한 인텔리전스 대시보드입니다.
선시안의 실제 매출(2025년 140.7억 원, 영업이익률 53%)을 기반으로 인앱 패키지별 유저 혜택(ROI)을 역산하고,
IAP·광고·B2B 스폰서십으로 구성된 하이브리드 BM 전략과 글로벌 국가별 타겟팅 방향을 시각화합니다.
또한 Gemini AI 연동을 통해 재화 구성과 판매가를 입력하면 최적의 패키지명·타겟·세일즈 포인트를 자동 제안하는 BM 기획 도구를 포함합니다.
던전앤파이터·니케 등 국내 주요 100만 DAU 게임과의 연매출 비교를 통해 캐주얼 인디 게임의 수익 구조적 한계와 가능성을 함께 조명합니다.
